# Portfolio — Martina Lopardo

Sitio de presentación profesional desarrollado con HTML, CSS y JavaScript puro, sin frameworks.

[lopardomartina.github.io](https://lopardomartina.github.io)

---

## Características

- Tema oscuro/claro con persistencia en localStorage
- Animación SVG del nombre generada a mano con paths
- Partículas animadas en el hero
- Diseño responsive (mobile first)
- Animaciones de entrada al hacer scroll (IntersectionObserver nativo + AOS)
- Formulario de contacto con mailto
